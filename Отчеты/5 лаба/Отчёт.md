# Отчёт по домашнему заданию: SLI, SLO, SLA

## 1. Стек мониторинга и реализация пробера

Для сбора и хранения метрик используется связка **Victoria Metrics (single-node)** и **vmagent**.  
Для оценки доступности "снаружи" реализован пробер на базе **Blackbox Exporter** и кастомного ресурса **VMProbe**.  
Пробер раз в 15 секунд опрашивает эндпоинт `/actuator/health` бэкенда и корневую страницу фронтенда, записывая результат в метрику `probe_success` (1 — успех, 0 — сервис недоступен).

## 2. Выбранные метрики и формулировки SLI

В качестве SLI (Service Level Indicators) выбраны три метрики, отображающие доступность, производительность и бизнес-ценность приложения (модель **RBSLO** — Request Based SLO).

### SLI 1: Доступность HTTP-сервиса (Availability)

- **Описание:** Доля успешных HTTP-запросов (статус-код < 500) от общего числа запросов к API.
- **Метрика:** `http_server_requests_seconds_count` (из Spring Boot Actuator).
- **Формула (PromQL):**

```promql
sum(rate(http_server_requests_seconds_count{status!~"5.."}[5m]))
/
sum(rate(http_server_requests_seconds_count[5m]))
```

### SLI 2: Задержка HTTP-запросов (Latency)

- **Описание:** Доля запросов, которые выполняются быстрее 500 миллисекунд.
- **Метрика:** `http_server_requests_seconds_bucket` (гистограмма).
- **Формула (PromQL, с использованием встроенной функции VictoriaMetrics):**

```promql
histogram_share(0.5, sum(rate(http_server_requests_seconds_bucket[5m])) by (le))
```

### SLI 3: Инфраструктурная доступность (Prober)
*   **Описание:** Доля времени, в течение которого эндпоинт здоровья приложения отвечает на внешние запросы.
*   **Метрика:** `probe_success` (от Blackbox Exporter).
*   **Формула (PromQL):**

```promql
    avg_over_time(probe_success{job="blackbox"}[5m])
```

## 3. Формулировка SLO и SLA

- **SLO (Service Level Objective)** — внутренняя цель команды разработки/эксплуатации. На графиках отображается как горизонтальная линия.
- **SLA (Service Level Agreement)** — внешнее обещание пользователям (с учётом штрафов). Отображается как вторая горизонтальная линия ниже SLO.
- **Окно оценки — rolling 30 дней.**

| Показатель           |           SLO (Цель) |       SLA (Гарантия) | PromQL для линии на графике       |
| -------------------- | -------------------: | -------------------: | --------------------------------- |
| Доступность (HTTP)   |                99.5% |                99.0% | `vector(0.995)` и `vector(0.99)`  |
| Задержка (Latency)   | 95% запросов < 500ms | 90% запросов < 500ms | `vector(0.95)` и `vector(0.90)`   |
| Доступность (Prober) |                99.9% |                99.5% | `vector(0.999)` и `vector(0.995)` |

**Общий SLA для приложения (30 дней):** composite SLI ≥ 89.0% («успешно и быстро»),
отдельные обязательства — HTTP ≥ 99.0%, latency ≥ 90% < 500 мс,
prober ≥ 99.5%.
